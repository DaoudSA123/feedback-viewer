    Next steps

    Analyzing comments
    • Download the comments and read a sample before drawing conclusions.
    • Group comments by theme (for example: can't find information, unclear content, broken link, technical problem).
    • Count how often each theme comes up and note the pages where it happens.
    • Only use AI tools approved by your department, and remove any personal information first.
    Designing interventions
    • Start with the most common theme on the pages with the most "no" clicks.
    • Write the problem as a user need ("I need to know how long processing takes").
    • Choose the smallest change that could fix it: reword, move content up, fix a link or add a missing answer.
    • Make one change at a time, then generate this report again after a few weeks to compare the "yes" rate.
